Этот репозиторий содержит пример использования Yandex DataSphere. Полное практическое руководство можно найти [здесь](https://yandex.cloud/docs/datasphere/tutorials/).

В практическом руководстве на примере простой сверточной нейронной сети CNN показано, как организовать эксплуатацию модели, обученной в Yandex DataSphere, с помощью Yandex Cloud Functions. Пример создан на основе [данного практического руководства](https://pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html) PyTorch.

`my_nn_model.py` — архитектура нейросети.

`train_classifier.ipynb` — загрузка обучающей выборки датасета CIFAR10 и обучение нейронной сети, описанной в файле `my_nn_model.py`. Веса обученной модели будут сохраняться в хранилище проекта в файл `cifar_net.pth`.

`test_classifier.ipynb` — загрузка архитектуры модели и весов, созданных во время обучения. Модель используется для прогнозов на тестовой выборке.
